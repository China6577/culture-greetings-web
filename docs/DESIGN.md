# 视觉与交互约定

**项目**：culture-greetings-web / 拾笺 Kinship。

核心视觉是一张可以更换文化画布的旅行明信片，面向希望向亲友表达祝福的人。首页让用户先理解“文化可选择、心意由自己书写”，然后开始创建。

## 设计取舍

首页采用左侧文字、右侧纸质明信片的非对称构图，下方保留创建入口。按设计反馈，删除文化藏品展示和三步介绍区，并移除指向已删除区域的按钮。通过右上角国家菜单同步切换主题与固定语言；菜单采用纸色圆角浮层、国家缩写色块、语言说明和选中勾选，不使用系统原生选项列表。不提供独立语言入口或文化探索标签页。编辑器保留实时 H5 卡片。

设计技能的数据库初始匹配推荐了动态粗野主义和深色背景，与本项目的 Apple / Airbnb / Canva 方向冲突，未采纳。保留其关于层级、可访问性与减少动画的建议；视觉按用户提供的各国主题色重新设计。

## 默认文化色板

| 角色   | 颜色    | 用途                       |
| ------ | ------- | -------------------------- |
| 朱红   | #C8102E | 中国主题主色、印章灵感     |
| 金色   | #FFD700 | 文化配置中的辅助色         |
| 绢纸   | #FFF7E6 | 页面背景                   |
| 纸白   | #FFFCF5 | 卡片与表单                 |
| 墨色   | #302D29 | 正文和标题                 |
| 深朱红 | #A2112B | 需要可读性的按钮与强调文字 |

每种文化使用独立的 primary / secondary / background / accent / ink / surface 令牌。粉色与金色用于主题色，操作文字使用更深的 accent 色。

## 排版与留白

品牌展示名随语言变化：中文“拾笺”、日文“結び”、英文“Kinship”、法文“Liens”。国家和语言选项、页脚、浏览器标题及明信片上的固定标题统一从本地翻译资源读取。项目目录与工程标识仍为 culture-greetings-web。

- 展示标题：本机衬线字体；中文使用宋体/系统衬线，日本主题使用 Yu Mincho。
- 美国与 Global：系统无衬线标题，形成现代庆典或国际极简的不同节奏。
- 正文与操作：Segoe UI、苹方、微软雅黑等系统字体，不依赖外部字体服务。
- 主内容最大宽度 1280px；桌面双栏、手机单栏；文化卡片在手机切换为两列。
- H5 画布首选 9:16 比例，长消息允许内容向下扩展，避免截断用户原文。

## 动效职责

- GSAP：统一入口中的按主题配置入场（墨迹感、展开、庆典、信件、手绘、淡入）。
- Framer Motion：路由页面过渡。
- Lottie：生成准备时的本地三点呼吸动画；使用 ESM 包与无表达式的轻量播放器。
- CSS 环境层：金色粒子、花瓣、彩带、信件光痕、光影与轨迹。
- 页面关闭动画或系统开启 reduced motion 时停止装饰动画。

## 可访问性

可见表单标签、就近错误提示、首次错误聚焦、语义导航与按钮、44px 级触控区、键盘焦点及跳转正文链接。对文化主题的选中状态使用勾选和文字，同时提供 aria-pressed。移动菜单提供 aria-expanded。文化插画与用户内容在本机展示，无外部图片热链。
