# culture-greetings-web · 界面设计

延续现有纸色、文化字体和各国家强调色。首页说明用途，创建页仅收件人/署名、可选祝福及单个需求描述框，不提供实时预览、模板选择或草稿保存。

创建页仅显示“创建贺卡”，作品页仅显示“我的贺卡”，均使用同一 page-title 字体、字号和标题间距，移除眉题与说明段落。列表右上角提供等宽等高的批量删除和创建入口；批量模式显示全选本页、已选数量和“删除”按钮，卡片右下角出现复选框，点击卡片或复选框均可切换选中状态，选中时显示边框。确认弹窗列出选定作品，翻页或退出批量模式清空选择。普通模式保留右下角单张删除，点击卡片查看，取消额外“打开贺卡”选项。

生成页面展示八项真实步骤：理解需求、文化策划、文案创作、视觉设计、动效设计、方案审核、图片生成、检查保存。严格从上到下执行，上一步完成才启动下一步；审核修订时按文案、视觉、动效、审核依次执行，相关角色回到进行中。事件来自后端，不设展示时长、假进度百分比或伪聊天回复。错误直接说明认证、服务、额度、超时或审核问题。

成品为 AI 插画背景加独立文字层，保持原文可选、可读。贺卡居中，下方仅静态/H5 切换和分享。动效角色生成每张作品的动画参数：水彩花瓣缓落、细碎星光、轻盈彩纸、线条烟花或柔和光晕。色彩取自本张贺卡，密度与节奏受场景和用户要求约束，装饰只进入插画区域或两侧边缘，文字固定。无新增动效设置面板，静态默认不挂载装饰，H5 连续播放且不重载图片，遵循系统减少动画偏好。

我的贺卡采用纸质作品网格、静态缩略图和国家/收件人/日期摘要。每页 12 张、页码导航、删除确认和空末页回退继续保留；窄屏单列，翻页和弹窗适应手机宽度。国家变化时界面文字与品牌同步变化，已生成作品保留创作时的国家语言。

列表页面代码和样式随应用加载，避免点击时再经过整页加载提示。首次请求用静态卡片占位预留网格位置；返回已访问的列表页时立即显示内存中的记录，并向服务端重新请求，更新时保留卡片节点和当前有效选择。内存最多保留五页，刷新浏览器即清空，不写入本地存储；生成完成或删除成功会使列表缓存失效，删除前开始的旧请求不能重新写入缓存。

旧 SVG 贺卡模板和检索推荐组件已删除。首页的文化插画属于网站品牌展示，不作为生成结果或失败回退。
